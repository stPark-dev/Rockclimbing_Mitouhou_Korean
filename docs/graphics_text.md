- 산·등반 지형 텍스처(X/YAMA*, KABEDAT)에는 글자가 없다(K_C6의 로마자 바위 무늬만 있음).
- 목록 작성 때의 전수 조사는 첫 블록이 0x74·0x73인 스트림만 찾았다. 첫 블록이 0x20·0x40·0xFF인 그림(예: type B 버튼 배치 0x105B4)은 빠졌을 수 있어 다시 조사해야 한다.
- 영상(MOVIE*.STR)은 압축 그림이 아니라 따로 조사해야 한다(미조사).
