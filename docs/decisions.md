# 결정 기록

## D1. 그림 글자 범위 (2026-10-21, 사용자 결정)

- 질문: 그림으로 된 글자를 어디까지 한글화할까.
- 근거 기준: `docs/survey.md` §2 (그림 글자는 목록만 작성, 위치 미조사).
- 선택지: 일본어 그림만 / 영어 버튼 포함 전부 / 런타임 글자 먼저.
- **결정: 일본어 그림만.** 타이틀 로고(ロッククライミング 未踏峰への挑戦), 데이터베이스 분류 라벨 등 일본어 그림 글자는 한글로 바꾸고, GAME START·CONFIG·NEW GAME·LOAD GAME·SAVE GAME 같은 영어 그림 글자는 원문 유지.
- 영향: 그림 글자 위치·형식 조사와 `0x74` 압축 형식 해독이 범위에 들어온다(그림이 그 안에 있으면).
- 재검토: 일본어 그림이 영상(STR) 안에 있는 것으로 드러나면 영상 범위를 따로 결정한다.

## D2. 이름 입력 (2026-10-21, 사용자 결정)

- 질문: 가나 표 이름 입력을 어떻게 할까.
- 선택지: 한글 입력 표로 교체 / 영문만 남김 / 나중에 결정.
- **결정: 한글 입력 표로 교체.** 가나 표를 한글 음절 표로 바꾼다. 기본 이름 クライマー도 한국어로.
- 영향: 입력 표에 넣는 음절은 글꼴 칸을 차지한다(survey §5). 표에 넣을 음절 수와 구성은 번역 음절 집합과 칸 여유를 본 뒤 다시 제시한다. 이름 저장 구조와 다른 화면(프로필 등)에서의 재표시를 조사해야 한다.
